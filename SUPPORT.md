# Support

Use:

- GitHub Issues for reproducible bugs;
- GitHub Discussions for setup and usage questions, once enabled;
- the comprehensive [README](README.md) for installation, calibration, operation, and troubleshooting.

Before requesting help, include operating system, Python version, robot model and firmware, tool, camera model, exact error text, and sanitized reproduction steps.

Never post API keys, camera unique IDs, serial-port identifiers, or a real `data/workcell.json`.

This is experimental robotics software, not a safety-rated controller. Stop physical testing when behavior is unexpected.
